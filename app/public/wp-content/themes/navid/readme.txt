== Description ==

Navid is a modern, blazing-fast magazine and blog WordPress theme crafted for publishers, editors, and daily news portals. Whether you are running a personal tech blog, a lifestyle magazine, or a heavy-content newspaper, Navid delivers a premium reading experience. It features a cinematic hero section, a beautiful dark mode, sticky headers, a dynamic bento box grid, and a classic marquee news ticker. Built with SEO and core web vitals in mind, it provides the perfect typography and layout to keep readers engaged. Navid is highly customizable and works seamlessly with popular page builders like Elementor, as well as Gutenberg block libraries like Kadence Blocks and Spectra. Perfect for daily journalism, creative portfolios, review sites, and modern editorial platforms.

**Key Features:**

* **Cinematic Hero Section** - Beautiful featured post highlights with parallax depth
* **Bento Grid Layout** - Modern, asymmetrical grid layouts for your latest stories
* **Scrolling Marquee** - Eye-catching trending post ticker with smooth infinite scroll
* **Dark Mode** - Elegant built-in dark/light mode toggle
* **Top Bar** - Configurable info bar with social links, tagline, and date display
* **Color Palettes** - Visual swatch-based color system with curated presets
* **Dynamic Category Colors** - Unique color-coded pills for each post category
* **Customizer Options** - Deep controls for colors, layouts, and typography
* **Fast Loading** - Extremely lightweight, zero jQuery, and optimized for core web vitals
* **Translation Ready** - Fully translatable and RTL language support
* **Responsive Design** - Pixel-perfect scaling from mobile phones to 4K desktop screens
* **WooCommerce Compatible** - Ready for online stores

**Perfect For:**

* Editorial magazines and online publications
* Lifestyle and wellness blogs
* Tech and business news sites
* Creative writers and storytellers

== Installation ==

1. In your admin panel, go to Appearance -> Themes and click the 'Add New' button.
2. Click 'Upload Theme' and choose the navid.zip file.
3. Click on the 'Activate' button to use your new theme right away.
4. Navigate to Appearance > Customize in your admin panel to configure your hero section, color palette, and top bar.

== Frequently Asked Questions ==

= Is this theme good for a daily newspaper or news portal? =
Yes! Navid was specifically built to handle high-volume publishing, making it the perfect newspaper theme for daily news, journalism, and editorial magazines.

= Does it work with Elementor and Kadence Blocks? =
Absolutely. Navid is a highly versatile blog theme that integrates perfectly with Elementor, Kadence Blocks, Spectra, and other popular site builders.

= How do I set up the hero section? =

Go to Appearance > Customize > Hero Section. You can set a custom title, subtitle, and featured image. The hero automatically displays your latest featured post.

= Can I customize the color palette? =

Yes! Go to Appearance > Customize > Colors & Style and choose from curated palette presets (Sage, Ocean, Rose, Midnight, etc.) or set a custom primary color.

= How do I enable the Top Bar? =

The top bar is enabled by default. You can configure it in Appearance > Customize > Top Bar with custom tagline text, social media URLs, and an optional date display.

= Is the theme translation ready? =

Yes, Navid is 100% translation ready and localized for global audiences.

= What's the difference between Navid (Free) and Navid Pro? =

Navid Free includes:
- Core cinematic hero section and bento layouts
- Dark mode toggle and color palettes
- Top bar with social integrations
- Deep customizer color controls

Navid Pro (Coming Soon) unlocks:
- Advanced Layouts & 1-Click Demo Importer
- WooCommerce deep integrations
- Infinite scroll / Ajax loading
- Premium widgets and custom post layouts
- Native newsletter platform API integrations
